# silverback-auto
README - Vehicle Repair Service Static Website

Project Overview
A responsive static website for a professional vehicle repair service, built with HTML, CSS, JavaScript, and Bootstrap. The site showcases automotive repair services and includes a contact form powered by FormSubmit.

Live Demo
[ https://mpumelelo-kenny-gabuza.github.io/silverback-auto/ ]

Features
Responsive Design: Mobile-first approach with Bootstrap grid system

Service Showcase: Display of vehicle repair services with detailed descriptions

Contact Form: Integrated with FormSubmit for handling inquiries

No Backend Required: Fully static implementation with no database

Interactive Elements: JavaScript-enhanced UI components

Modern UI: Clean, professional design tailored for automotive services

Technologies Used
HTML5: Semantic markup structure

CSS3: Custom styling with responsive design

JavaScript: Client-side interactivity

Bootstrap 5: Responsive framework components

FormSubmit: Contact form processing

Font Awesome: Icon library for visual elements
